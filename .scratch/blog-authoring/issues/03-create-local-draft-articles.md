# 03: 创建本地草稿文章

**What to build:** 博客作者可以通过安装后的 `yoho blog create <id>` 创建可被既有博客读取的草稿，选择 Markdown 或 MDX、输入正文与标签，并在重复请求或并发创建时保留已有文章。

**Blocked by:** 02: 更新描述与标签。

**Status:** resolved

**Spec:** [第二个里程碑规格](../spec.md)。

- [x] `create` 沿用现有项目自动定位和 `--project`，只在已识别的博客内创建文章；无项目时明确失败，不自动初始化博客。文章标识沿用既有相对路径规则，支持创建子目录。
- [x] 必须提供 `--title`、`--description` 和 `--published-at`。标题沿用非空单行及首尾空白处理，描述允许空字符串且不修剪；缺失或无效参数返回参数错误。
- [x] 日期接受有效 ISO 日期或带时区的 ISO 时间；仅日期按 UTC 零点解释，带偏移时间转换到 UTC。拒绝不存在的日期、无时区时间与日期自动滚动，写入既有博客能读取的 UTC ISO 字符串。
- [x] `--format` 只接受 `md`、`mdx`，默认 `md`。`--body-file` 省略时正文为空；提供时复用正文文件的路径、UTF-8、普通文件与原样保留规则。可重复 `--tag` 复用标签规范化规则，省略时为空列表。
- [x] 新文章明确写入标题、描述、发布日期、`status=draft`、`draft=true`、`language=zh` 和标签，不自动写入 `updatedAt`。创建不接受已发布或归档状态。
- [x] 新建 frontmatter 为合法 YAML，正文原样接在结束分隔符之后，不额外补充正文空白或换行。创建结果与随后 `show` 的正文、元数据和文章版本一致。
- [x] 文章标识的任一扩展名已占用时返回 `ARTICLE_ALREADY_EXISTS`，退出码为 3，包括原文已损坏的情形；已有两个候选文章时报告 `ARTICLE_ID_AMBIGUOUS`。目录或其他非普通文件占据目标时明确失败，绝不覆盖。
- [x] 拒绝路径越界，且在目标尚不存在时仍检查已有父目录及最终候选位置。创建路径的目标或内容目录以内的父目录含符号链接时按规格拒绝；越界返回 `PATH_OUTSIDE_CONTENT`，目录内链接返回 `ARTICLE_INVALID`。
- [x] 创建与已有所有更新对相同文章标识采用共享互斥规则，覆盖目标尚不存在及不同扩展名竞争。原有标题与正文更新一并迁移到一致规则，并保持目录内链接更新已有的锁保护。
- [x] 并发创建相同文章标识时至多一个成功，包括两个请求选择不同扩展名的情况。重复请求明确报目标已存在，不声称成功覆盖或产生两个候选文章。
- [x] 新文章提交不暴露半成品，不覆盖并发产生的目标。提交前错误或取消不留下新文章，正常失败清理暂存内容与本次锁，允许保留新建的空父目录。锁与暂存内容不参与文章列表解析。
- [x] 不检查其他文章内容来决定创建是否成功。其他文章损坏不影响合法新目标，输入正文文件保持不变。
- [x] 成功返回与 `show` 一致的 `id`、`path`、`metadata`、`content` 与 `revision`。文本显示创建结果；JSON 成功和失败沿用 stdout 协议、诊断通道与退出码，调用无需交互。
- [x] 通过安装后的 CLI 验证普通与子目录创建、两种格式、空正文、中文与引号、标签、日期时区、参数错误、目标占用、损坏原文、并发重复、路径边界、权限、I/O 错误与取消，检查目标及输入文件的实际内容。
- [x] 使用博客实际内容加载器确认创建文章符合契约且草稿不公开。回归列表、查看、标题与多字段更新以及并发版本检查，并更新草稿创建说明。
