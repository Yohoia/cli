# 05: 预览文章删除

**What to build:** 博客作者和本地产品可以通过安装后的 `yoho blog delete <id> --dry-run` 查看将删除的文章标识、位置与文章版本。预览不移除文章，也不创建锁或其他持久文件。

**Blocked by:** None (can start immediately).

**Status:** resolved

**Spec:** [第二个里程碑规格](../spec.md)。

- [x] 安装后的 CLI 提供删除预览，沿用项目定位、`--project`、`--json` 及子目录文章标识，不依赖新建文章命令建立样本。
- [x] 预览定位并读取目标文章，返回 `id`、`path`、`revision`、`dryRun=true` 与 `deleted=false`；文本明确显示尚未删除，不能将预览报告成实际删除成功。
- [x] 支持可选 `--if-match`。版本匹配或未提供版本时返回当前预览；版本过期返回 `ARTICLE_CONFLICT`，退出码为 3，文章保持原样。
- [x] 预览不要求 `--yes`；同时提供 `--dry-run` 与 `--yes` 仍只预览。此任务不接通实际删除，未指定预览模式时非交互失败，实际执行由任务 06 完成。
- [x] 不创建文章目录、锁、暂存文章或其他持久文件，不改变目标及其他文件的内容或修改时间。预览不预留目标，后续实际删除需用 `--if-match` 保证版本一致。
- [x] 不存在目标返回 `ARTICLE_NOT_FOUND`；损坏文章、非普通文件或 Markdown、MDX 歧义明确失败。只检查目标，其他文章损坏不阻止正常预览。
- [x] 拒绝越界路径，以及逻辑目标或内容目录以内的父目录为符号链接的路径。越界返回 `PATH_OUTSIDE_CONTENT`，指向目录内的链接返回 `ARTICLE_INVALID`，不通过解析链接预览另一篇文章作为删除目标。
- [x] JSON 成功与失败均独立写入 stdout，stderr 只承载诊断，沿用规格退出码，完整参数调用无需交互。权限、读取错误与取消均明确报告且不产生持久变更。
- [x] 通过安装后的 CLI 验证普通与子目录预览、版本匹配和过期、预览加授权、不存在、损坏、歧义、链接及边界错误；比较目录与文件前后状态，证明没有锁或暂存残留。
- [x] 回归既有列表、查看和更新命令，并更新删除预览说明，明确只读预览与后续实际删除之间的版本关系。
