# 06: 授权并执行文章删除

**What to build:** 博客作者和本地产品在确认目标后，可以通过 `yoho blog delete <id> --yes` 删除指定文章，也可以使用预览得到的文章版本执行条件删除。删除只影响目标，并与创建和更新遵守同一并发保护规则。

**Blocked by:** 03: 创建本地草稿文章；05: 预览文章删除。

**Status:** ready-for-agent

**Spec:** [第二个里程碑规格](../spec.md)。

- [ ] 在既有删除预览命令中接入实际执行。没有 `--dry-run` 时必须提供 `--yes`；缺少授权返回 `INVALID_ARGUMENT`，退出码为 2，不等待终端输入，不修改文章。
- [ ] 同时提供 `--dry-run` 与 `--yes` 时继续只预览。授权参数不绕过路径、文章数据、符号链接、歧义或文章版本校验。
- [ ] 实际删除沿用预览的目标校验，并在与创建、更新一致的锁保护下重新读取当前文章，核对路径、锁有效性与提交前内容。未提供版本时基于当前文章删除。
- [ ] `--if-match` 只在文章版本匹配时允许删除；预览后正文或元数据发生变化，旧版本删除返回 `ARTICLE_CONFLICT`，退出码为 3，保留新内容。
- [ ] 成功只移除目标文章，不删除图片、附件、其他文章或父目录。返回 `id`、`path`、被删除文章的 `revision`、`dryRun=false` 与 `deleted=true`，文本明确显示实际删除结果。
- [ ] 成功删除后，查看与重复删除均返回 `ARTICLE_NOT_FOUND`，退出码为 3；正常列表不再包含目标，不把重复删除报告为成功。
- [ ] 目标不存在、损坏、非普通文件、歧义、越界或含被禁止的链接时，不执行删除。其他文章损坏不影响有效目标，不增加强制删除损坏文章的入口。
- [ ] 两个携带相同旧版本的更新与删除请求不能同时基于该旧版本提交成功。并发删除、删除与创建使用同一文章标识互斥规则，结果不出现半篇文章或双扩展名歧义。
- [ ] 提交前取消、权限错误、I/O 错误或锁失效保持原有文章完整，正常失败清理本次暂存内容并释放锁；提交完成后不因清理失败回滚已完成的删除。沿用锁竞争、超时与过期锁处理规则。
- [ ] JSON 成功与失败沿用 stdout 结果协议和既有退出码，诊断不污染结果，完整参数调用无需交互。保留删除预览全部行为。
- [ ] 用安装后的独立 CLI 进程验证删除授权、预览优先、当前版本成功、旧版本拒绝、重复删除、目标隔离、边界、权限、I/O 错误和取消；直接比较文章、图片与父目录的实际状态。
- [ ] 使用临时博客验证更新与删除持相同旧版本竞争、删除与创建竞争以及锁释放后的后续操作，并回归此前已支持的命令。所有实际删除都使用临时样本。
- [ ] 从最终本地安装包完成已就绪功能的创建、编辑、删除预览和实际删除流程，并更新授权、版本检查、删除范围和不提供恢复的使用说明。整个里程碑在全部任务合入后按父规格完成累计验收，不能以本任务单独通过代替状态管理等并行任务的验收。
