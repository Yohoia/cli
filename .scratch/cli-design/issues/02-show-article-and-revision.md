# 02: 查看完整文章与文章版本

**What to build:** 用户和本地产品可以通过 `yoho blog show`，按文章标识查看完整文章及其文章版本，为后续编辑获取明确目标和内容状态。

**Blocked by:** 01: 安装 CLI 并列出文章。

**Status:** resolved

**Spec coverage:** 用户故事 9–15、26、31–34、35–40、42。本任务复用 01 的可安装命令、项目定位、内容契约和输出规则。

- [x] 安装后的 CLI 提供 `yoho blog show`，通过文章标识读取目标，支持子目录文章标识以及既有 Markdown、MDX 文章。
- [x] 查看结果包含完整正文、全部元数据、文件位置和文章版本；未知元数据仍可查看，图片引用保持原始形式，不执行站点展示转换。
- [x] 文章版本标识读取时的内容状态，可供后续条件更新使用；文章内容变化后，查看结果能反映新的文章版本。
- [x] 查看不改变原文件、文章标识、默认字段的持久化状态或图片引用。
- [x] 只校验目标文章；其他文章损坏时，仍可查看正常目标。目标文章损坏时，错误指出目标文件。
- [x] 目标不存在时返回 `ARTICLE_NOT_FOUND` 及规格约定的文章数据错误退出码。
- [x] 同一文章标识同时对应 Markdown 与 MDX 文件时报告歧义，不猜测目标。
- [x] 拒绝访问文章目录之外的文件，包括利用路径或符号链接越界的情况。
- [x] 文本和 JSON 模式均可使用，完整参数调用无需交互；成功、失败、诊断通道和退出码遵循 01 已落实的公共契约。
- [x] 使用安装后的 CLI 子进程验证完整内容、未知字段、原始图片引用、文章版本、子目录标识、不存在目标、歧义、越界和目标检查范围，并验证读取不会修改文件。
