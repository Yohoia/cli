# Mole 风格交互入口

日期：2026-10-28。用户明确要求输入 `yoho` 进入菜单，视觉和键盘操作以本机 Mole 1.64.0 及用户提供的两张 120×30 终端截图为准。此约定替代旧规格中要求用户先输入具体业务命令才能进入交互的入口约定；文章 API、Skill 写入及 JSON 契约继续遵循现有规格。

## 入口与外观

- 交互终端运行 `yoho` 打开持久主菜单：Blog、Skill、Auth、Settings。菜单支持方向键、J/K、数字、Enter、M 帮助、V 版本、Q/Esc 退出。
- `yoho blog`、`yoho skill` 可直接打开对应页面。已有完整子命令继续可用；无终端时显示帮助，`--json` 缺少业务子命令时报参数错误。
- 首页采用绿色 Yoho ASCII 字标、青色焦点行、编号菜单及灰色按键说明。列表使用紫色标题、圆圈选中标记、固定列比较及底部按键说明；继承终端字体和背景。
- 宽屏以 120×30 为参照，窄屏收缩列并换行按键说明。NO_COLOR 关闭颜色，TERM=dumb 显示命令帮助。
- 独占 raw stdin 及备用屏幕；退出、异常和 Ctrl+C 恢复光标、输入模式和主屏幕。焦点/选择即时重绘，加载时显示可取消的 spinner。

## 列表与业务操作

- 共用方向键/J/K 移动、Space 勾选、A 全选/清空、Tab 反选、Enter 打开、/ 即时搜索、S 切换排序字段、O 切换排序方向、H/L 翻页、R 刷新、Q/Esc 返回。
- 批量操作处理当前筛选内已勾选项；没有勾选时处理焦点项。搜索条件开始编辑时清除选择，避免隐藏项被误操作。
- Blog 读取全部服务器分页后在本机搜索、排序及按视口分页。Enter 读取完整文章，N 输入 Markdown 路径创建草稿，P 发布，D 软删除。
- 发布/删除先查询文章或删除预览，显示目标、状态及版本；确认默认取消，确认后原样传回版本。多个目标逐项返回结果；结果未知或取消时停止后续写入并显示原请求编号。
- Skill 显示本机安装状态和声明版本；Enter 展示来源、说明和实际安装位置。I 安装后选择范围与多个标准目标，U 覆盖更新已有位置，D 预览并确认卸载，M 进入来源管理。
- 来源页支持查看、添加、移除；卸载保留来源，来源移除保留文件。Auth 提供登录、状态及注销，Settings 保存默认服务器。
- 交互层以完整参数和 JSON 调用同一安装包入口，不复制业务权限、版本、恢复和文件写入逻辑。子命令 stderr 在操作页显示；取消等待子命令清理完成。

## 验收

使用真实安装包、隔离 HOME/配置、Codeup Git 夹具、临时 PageHush API 和真实 PTY。验证文件与远程回读结果、默认取消、搜索选择范围、备用屏幕/光标恢复、子进程取消和既有非交互 JSON 契约。结构及完整回归按项目规范执行。视觉证据从真实 PTY 屏幕单元格生成，保存在 `artifacts/cli-style/mole-interactive/`。
