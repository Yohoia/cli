## 验收边界与后续操作

- 以上测试使用临时数据库、隔离配置与凭据、FakeStorage 和本机 HTTP；没有读取生产 `.env` 或向真实文章库写入。
- 真正并发断言使用临时 PostgreSQL；PGlite 只承担协议、安装包和网页测试中的隔离数据库边界。
- 验收结束后，临时 PostgreSQL 中测试 schema 数为 0，实例已停止且临时数据目录已删除；保留安装好的 PostgreSQL 工具。测试服务器与临时 Keychain 均由测试清理。
- 手动授权通过 `--no-browser` 与真实网页手填设备码验证。自动打开浏览器失败后的提示分支经过代码审查，未通过修改系统浏览器配置强行制造失败。
- 保守的 MDX 素材保护不执行动态代码；出现已知素材 ID 时可能多保留未使用的素材，避免误删已有文章所用图片。
- 迁移无法还原旧系统中已经撤回草稿的首次发布历史；这类草稿再次发布时由服务器记录当前日期，详见 PageHush `docs/remote-cli.md`。
- 本轮仅完成本地提交，尚未推送、部署或公开发布 npm 包。线上使用前需配套升级 PageHush API、网页并执行迁移，再按 README 安装 CLI 和运行 `yoho auth login`。
