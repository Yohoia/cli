## 本机安装

已从本地发行包全局安装到用户目录，无需系统目录权限：

```sh
npm install --global --prefix "$HOME/.local" ./artifacts/yoho-cli-0.3.0.tgz
```

本机已有 `$HOME/.local/bin` 的 PATH 配置，未修改 shell 配置。实际命令位于
`~/.local/bin/yoho`；从 `/tmp` 调用版本及帮助成功。当前尚未批准生产服务的设备授权，
`yoho auth status --json` 返回 `AUTH_REQUIRED`（退出码 4）。首次使用需本人运行
`yoho auth login` 并在 PageHush 网页批准。
