# 01: 设备登录并读取远程文章列表

Status: ready-for-agent

**What to build:** 安装后的 CLI 发起设备授权，网页批准或拒绝；签发默认 30 天有效的受限令牌，按服务地址保存，登录后能读取第一页远程文章。覆盖取消、凭据存储失败、环境变量令牌与服务覆盖。

**Blocked by:** None (can start immediately)。

- [ ] 覆盖手动网址回退、待批准、降速、拒绝、超时、取消、重复批准及只有成功才保存凭据。
- [ ] 服务地址覆盖与规范化隔离、系统凭据失败不降级明文、环境变量令牌不落盘。直接调用 API 验证设备权限受服务器限制，未完成的写能力不能通过通用接口绕过。
- [ ] 按[正式规格](../spec.md)对应行为，使用隔离真实 API 与安装后的 CLI 或浏览器验证输出及持久化结果；不读取生产配置或写入线上文章。
