# 04: 上传无本地配图的 Markdown 草稿并查询结果

Status: ready-for-agent

**What to build:** 从 `.md` 路径提取字段，上传前拒绝空正文与无效输入，源文件不变；主动重复执行新增，网络重试去重；超时通过操作编号查询结果，至少七天可恢复且本地不存正文。

**Blocked by:** 01：设备登录并读取远程文章列表。

- [ ] 完整覆盖文档字段与标题回退、摘要、UTF-8、中文和空格路径、空正文预检、源文件不变、远程图片及已有素材地址保留。
- [ ] 尚不支持的本地资源先拒绝。验证同编号并发最多创建一次、不同内容冲突、响应丢失、进程取消、未知结果查询及至少七天结果保留。
- [ ] 旧编号过期后不能当作新请求重做，本地操作记录不保存正文或凭据。
- [ ] 按[正式规格](../spec.md)对应行为，使用隔离真实 API 与安装后的 CLI 或浏览器验证输出及持久化结果；不读取生产配置或写入线上文章。
- [ ] 并发保证使用独立临时 PostgreSQL 的多客户端验证；PGlite 和单请求顺序测试不能替代。
