# 05: 网页与 API 共同保护文章版本

Status: ready-for-agent

**What to build:** 使用 02 提供的服务器文章版本，网页编辑、发布/撤回和删除都带版本，服务器原子检查；旧版本或缺条件明确失败，网页保留未保存输入，剪藏扩展新增兼容。临时 PostgreSQL 验证并发仅一方成功。

**Blocked by:** 02：完整查询文章列表与详情。

- [ ] 使用网页现有草稿验证全部文章修改、发布/撤回及删除入口，缺条件与旧版本均失败。
- [ ] 两个客户端基于同一版本的竞争不能同时覆盖成功。浏览器冲突后保留输入，现有剪藏扩展创建草稿兼容。
- [ ] 按[正式规格](../spec.md)对应行为，使用隔离真实 API 与安装后的 CLI 或浏览器验证输出及持久化结果；不读取生产配置或写入线上文章。
- [ ] 并发保证使用独立临时 PostgreSQL 的多客户端验证；PGlite 和单请求顺序测试不能替代。
