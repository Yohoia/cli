# 08: 自动上传 Markdown 本地内嵌图片

Status: ready-for-agent

**What to build:** 相对路径预检、重复引用复用、素材幂等上传、内存正文改写后创建草稿，源文件不变；任一图片失败不创建文章，CLI 只取得文章内嵌图片上传窄权限。

**Blocked by:** 04：上传无本地配图的 Markdown 草稿并查询结果。

- [ ] 验证相对及父目录路径、JPEG/PNG/WebP 与 5 MiB 上限、同图复用、代码示例跳过、所有本地资源先预检及任一图片失败不创建文章。保留 HTTP(S) 与已有素材地址，只改内存正文。
- [ ] 直接 API 验证上传绑定文章操作且仅允许内嵌图片，不能取得 MinIO 密钥或独立管理素材。覆盖相同素材请求并发去重、不同内容冲突、部分上传与提交失败的恢复，以及草稿素材沿用现有访问保护。
- [ ] 按[正式规格](../spec.md)对应行为，使用隔离真实 API 与安装后的 CLI 或浏览器验证输出及持久化结果；不读取生产配置或写入线上文章。
- [ ] 并发保证使用独立临时 PostgreSQL 的多客户端验证；PGlite 和单请求顺序测试不能替代。
