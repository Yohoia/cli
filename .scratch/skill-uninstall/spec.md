# 卸载本地 Skill，保留来源登记

2026-10-26：用户明确调整已确认行为，替换早期“卸载同时移除来源”的要求。卸载只删除本地文件和安装记录；source remove 单独负责移除来源。

## 行为

- yoho skill uninstall 为主命令，remove 为别名；支持多个名称、owner/repo、--all、--yes、--dry-run。
- 卸载所有可识别的本地目录及安装记录，始终保留来源登记及缓存元数据。卸载后 skill list 仍展示该 Skill，普通输出状态为 not installed，可以直接重新安装。
- --all 只卸载全部受管安装；重复卸载已卸载项或没有安装的来源是无操作，不会清空或重新播种来源列表。
- 默认发现当前项目、用户标准目录及其他已记录项目位置，只管理登记来源或历史记录。无来源匹配的第三方 Skill 不受影响。
- 完全离线。未知手动副本不靠仓库名猜测归属；源名称需要本地缓存与 SKILL.md 唯一对应。
- 无参数在终端多选；预览实际目录，确认默认取消；非终端执行必须 --yes；--dry-run 始终只预览。
- 逐目标卸载。失败位置保留记录供重试，成功位置不恢复；缺失目录仅清理残留记录。符号链接、父目录重定向、目录替换及中断备份保护继续有效。
- JSON stdout 单结果。兼容字段 removedSources 始终为空数组，其类型约束不允许填入已删除来源；预览 sources 表示相关来源，不表示删除来源。普通输出明确提示保留来源。
- source remove 仅移除来源，不删除本地文件。需要同时移除文件和来源时，由用户分别执行两个命令。
- 安装、更新和卸载继续共用方块进度条。

## 验收

使用安装包 CLI、临时 HOME/项目、本机 GitHub 夹具和真实 PTY，检查真实文件、记录、来源、退出码及输出。覆盖卸载后列表仍有全部来源、not installed、无需重新登记即可安装，以及 source remove 保留已安装文件。保留原预览、取消、批量、跨项目、权限错误、重试、歧义、链接及中断备份回归。

## 2026-10-26：默认入口为已安装列表多选

用户要求输入删除命令即展示列表，可选一项或多项。无名称的 uninstall / remove 读取本地受管安装，按 Skill 来源分组，显示安装位置数量，用 Clack 多选；不展示仅登记但未安装的来源，不展示未受管第三方 Skill。选定后仅处理勾选 Skill 的位置，保留目录预览、确认、方块进度及来源登记。无已安装项直接提示退出。完整名称及 --all 调用继续适用；损坏或需要恢复的目标不可被交互选择绕过。
