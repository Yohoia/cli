# 通过 PageHush 素材 API 上传文章内嵌图片

CLI 从本地 Markdown 创建文章时，正文引用的本地行内图片通过 PageHush 素材 API 上传，由服务端使用 MinIO 保存；CLI 不直接连接 MinIO，也不接收存储密钥。CLI 只在待提交的内存正文副本中将本地路径替换为稳定素材地址，源 Markdown 保持不变。

该流程只授予文章上传所需的内嵌图片窄权限，不提供独立素材管理；图片上传需要幂等请求和未引用素材清理，以避免文章创建重试或失败产生重复、孤立素材。文章创建失败时，服务器在至少七天后清理仍未被文章引用的素材。远程 URL、已有 PageHush 素材地址、普通附件和其他 Markdown 文档链接按各自规则处理，不把本地文件路径直接写入远程文章。
