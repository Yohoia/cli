# Skill 更新以来源仓库为准并按目标恢复

Skill 的安装和更新由 CLI 统一管理，更新时以来源仓库内容为准；用户明确选择覆盖本地修改，并删除仓库没有的本地新增文件，以避免每个 Skill 自行实现更新或长期保留安装目录中的内容分歧。更新支持全部或指定 Skill；手动安装项按 SKILL.md 的 name 与登记来源唯一匹配后建立来源关联，无匹配或歧义时跳过并报告。

批量更新以每个目标目录为恢复单位：写入失败只恢复该目标，已经成功的目标保留更新结果。这与首次批量安装的整批回滚规则不同，是用户为更新流程选择的行为。确认过程见 [Skill 管理讨论](../../.scratch/skill-management/notes.md)，最终行为和验收依据为[正式规格](../../.scratch/skill-management/spec.md)。
