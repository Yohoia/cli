## Spec

初审发现两项 P2 规格缺陷。

1. JSON 查看会静默丢失未知元数据。非有限数字会变成 null，YAML 集合会变成空对象，特殊自有键会在校验过程中消失。这不符合查看结果包含全部元数据的要求。
2. CLI 与博客的 YAML 标量语义不同。例如同一个前导零日期数字被解释成不同时间，不符合沿用既有博客内容契约的要求。当前真实文章使用普通日期，未发现已经受此差异影响。

已使用与博客相同的 `gray-matter` 解释元数据语义，保留未知集合及特殊自有键，并对非有限数字、循环引用明确返回文章数据错误。YAML 语法树继续用于定位源片段与约束别名展开，不决定业务字段的标量含义。

新增的 CLI 回归测试先复现失败，再验证修复，覆盖集合、特殊自有键、非有限数字及博客支持的旧式数字标量。规格审查员确认两项发现均可关闭，未发现阻止交付的同类兼容问题。

规格轴共发现两项 P2 问题，均已关闭，当前无未解决发现。
